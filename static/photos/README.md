# Photos

Upload JPG, PNG or WebP files. They are resized automatically when the site builds.

- `events/<event-slug>/`   photographs of one event (shown on its page once it is completed).
                           A file named `cover.jpg` becomes the event's main picture.
- `gallery/`               general photographs for the Gallery page.
- `slots/<name>.jpg`       the framed photo spaces on other pages. Names:
    hero, about-1, about-2, work, partners, bana-1, bana-structure

Captions and alt text: see README.md in the project root.
