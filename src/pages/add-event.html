How it works

  1. Fill in the form below. Choose an existing event to write its summary after it has taken place.
  2. Copy the result from the box on the right. Choose "Full events list" and copy it.
  3. Paste it into data/events.json in the website's GitHub repository (replace the whole file) and commit. The site rebuilds in about a minute.
  4. Add photographs by uploading them to the folder shown under "Photo folder". They appear on the event's page automatically.
